# Contribution and Source Notes

## Team and workflow

This repository reflects the Group G12 AI assignment workflow, including staged implementation and merge-based progress tracking. The work was completed in successive branch stages:

1. data validation and project skeleton
2. regression model and tests
3. classification stage
4. clustering stage
5. release packaging and prediction CLI

## Source of the dataset

The dataset used for training and validation is the lecturer-provided file in `data/AI_A1_G12.csv`.

## Model outputs

All generated artifacts are written to `artifacts/` and `models/`, with summary metadata captured in the model index file.

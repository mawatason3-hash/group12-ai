# AI Use and Disclosure

This project was developed as a supervised AI assignment for Group G12. The repository uses Python-based modeling workflows, automated validation, and structured reporting to train and evaluate the required statistical models.

## Scope of AI assistance

- data validation logic and pipeline structure were reasoned through with programmatic checks
- regression, classification, and clustering implementations were verified using pytest and project-specific metrics
- final packaging and documentation were assembled to match the assignment release checklist

## Responsible use

All outputs were checked against the dataset contract, the repository evidence, and the model artifact structure before final submission.

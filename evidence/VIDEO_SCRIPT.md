# Video Script (Short Presentation)

## Opening

"This project implements the AI assignment pipeline for Group G12. It loads the dataset, validates the schema, trains the regression model, evaluates the classification model, and explores clustering patterns in the same workflow."

## Key points

- strict validation keeps the dataset consistent and safe for modeling
- regression predicts actual yield from agronomic feature values
- classification identifies dispatch attention risk using balanced logistic regression
- clustering highlights natural operating profiles from the feature set
- the release package includes a prediction CLI and evidence folder

## Closing

"The final package is ready for execution, validation, and handoff with reproducible artifacts and documentation."
